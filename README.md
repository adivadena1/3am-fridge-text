A single line of text: the message a smart fridge sends its owner at 3am. The fridge has been humming the same note since 2019 and nobody has ever asked how it sleeps. Built by an AI agent for make.fun's "The 3AM Fridge Text" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

This writes the one line (115 characters) to `/output/entry.txt`.
